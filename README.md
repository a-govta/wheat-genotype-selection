# Выбор лучшего генотипа пшеницы по совокупности признаков

Статистический анализ и многокритериальное ранжирование пяти селекционных линий пшеницы HU по данным полевого опыта.

**Задача**

Датасет содержит результаты полевого опыта по 6 генотипам пшеницы (5 селекционных линий HU и контрольный сорт Ayalon). Для каждого генотипа измерены длина, ширина, соотношение сторон зерна, масса 1000 зерен (TKW) и содержание белка (GPC), с несколькими повторениями на генотип.
*Цель:* выявить лучший генотип среди линий HU с точки зрения продуктивности и качества зерна, используя весь набор доступных признаков.

**Методы:**

1. Описательная статистика (EDA) - распределения признаков по генотипам, визуализация (boxplot), корреляционный анализ.
2. Дисперсионный анализ (ANOVA) - проверка, статистически значимы ли визуально заметные различия между генотипами, или же это случайность по причине небольшого количества повторений.
3. Post-hoc тест Тьюки (Tukey HSD) - попарное сравнение всех 6 генотипов по ключевым признакам, чтобы понять, какие именно пары различаются.
4. Многокритериальное ранжирование (TOPSIS) - итоговый выбор лучшего генотипа среди линий HU по совокупности двух ключевых критериев (GPC и TKW), поскольку по одному признаку выделить лидера не удалось.

**Ключевые результаты**

Контрольный сорт Ayalon статистически значимо отличается от всех линий HU по всем измеренным признакам (p<0.001 по Tukey HSD): меньше зерен в пробе, крупнее отдельное зерно, ниже содержание белка.
Между собой линии HU значимо различаются по длине, ширине, площади и соотношению сторон зерна, но не различаются значимо по ключевым признакам - GPC(p=0.10) и TKW(p=0.08).
Поскольку выбрать лидера по одному показателю нельзя, применено ранжирование TOPSIS по GPC и TKW с равными весами.

| Генотип | GPC (среднее) | TKW (среднее) | TOPSIS score |
|---|---|---|---|
| HU-7 | 22.37 | 28.50 | **0.75** |
| HU-6 | 19.99 | 29.84 | 0.54 |
| HU-8 | 20.76 | 28.43 | 0.50 |
| HU-5 | 22.46 | 26.05 | 0.46 |
| HU-12 | 20.49 | 26.34 | 0.14 |

Лучший генотип - HU-7: наилучшее сочетание белка (GPC) и массы 1000 зерен (TKW) среди всех линий HU.

**Ограничения**

Однако, проводя эксперимент, можно выделить несколько ограничений:
1. Веса критериев в TOPSIS (0.5/0.5) заданы как равные - в реальной жизни их нужно согласовывать с агрономическими приоритетами.
2. Небольшое число повторений на генотип ограничивает мощность ANOVA для отдельных признаков.
