# Выбор лучшего генотипа пшеницы по совокупности признаков

Статистический анализ и многокритериальное ранжирование пяти селекционных линий пшеницы HU по данным полевого опыта.

## Задача

Датасет содержит результаты полевого опыта по 6 генотипам пшеницы (5 селекционных линий HU и контрольный сорт Ayalon). Для каждого генотипа измерены длина, ширина, соотношение сторон зерна, масса 1000 зерен (TKW) и содержание белка (GPC), с несколькими повторениями на генотип.
## Цель:
выявить лучший генотип среди линий HU с точки зрения продуктивности и качества зерна, используя весь набор доступных признаков.

## Методы: 
1. Описательная статистика (EDA) - распределения признаков по генотипам, визуализация (boxplot), корреляционный анализ.
2. Дисперсионный анализ (ANOVA) - проверка, статистически значимы ли визуально заметные различия между генотипами, или же это случайность по причине небольшого количества повторений.
3. Post-hoc тест Тьюки (Tukey HSD) - попарное сравнение всех 6 генотипов по ключевым признакам, чтобы понять, какие именно пары различаются.
